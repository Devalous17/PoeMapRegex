Current design and fonts

The current interface follows the project owner’s MapRegex / Sprite UI v2 Figma design. Its supplied sprite artwork is bundled unchanged. Cinzel headings and Inter body text are self-hosted under the SIL Open Font License. Cinzel license · Inter license.

Earlier supplied UI sheet

Buttons, frames, tabs and texture were extracted from the UI sheet supplied by the project owner. No new artwork was generated.

Fontin

Fontin and Fontin SmallCaps by Jos Buivenga (exljbris). The original unmodified files were restored from this project’s earlier local backup. Web font attribution is included beside each font-face declaration. Foundry web embedding terms · Bundled font notice.

Fallback fonts

Cormorant SC headings and Crimson Pro body text are self-hosted under the SIL Open Font License 1.1. Cormorant license · Crimson Pro license.

Background

The previously supplied Path of Exile background remains bundled for earlier themes; the current Figma theme uses its dark green background colors. Path of Exile artwork belongs to its respective owners. No additional game artwork is used for the UI icons.
