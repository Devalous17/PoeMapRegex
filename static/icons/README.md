# MapRegex icons

These icons are locally hosted, from Game-icons.net, under CC BY 3.0.
See manifest.json and /credits.html for individual authors and source links.

To replace an icon, replace the corresponding SVG file without changing its filename.
Use a transparent background and a square viewBox; opaque silhouettes become gold
through CSS masking. No source-code change is needed. Do not include scripts,
external resources, or embedded images. Update manifest.json and credits.html
with the replacement author, source, license, and changes. Rebuild the frontend.
Only use assets you have permission to redistribute.
